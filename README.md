# CajaLab

Generador web de cajas para corte laser inspirado en MakerCase.

## Funciones

- Vista previa 3D de la caja.
- Controles de ancho, fondo, alto, grosor, kerf y tamano de dedo.
- Caja con tapa o sin tapa.
- Exportacion SVG para corte.
- Exportacion DXF ASCII R12 en milimetros con capa `CUT`.

## Uso

Abre `index.html` en el navegador.
