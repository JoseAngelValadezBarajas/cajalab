# CajaLab

Generador web de cajas para corte laser inspirado en MakerCase.

## Funciones

- Vista previa 3D de la caja.
- Controles de ancho, fondo, alto, grosor, kerf y tamano de dedo.
- Unidades en milimetros o pulgadas.
- Medidas internas o externas.
- Presets de material.
- Caja con tapa o sin tapa.
- Exportacion SVG para corte.
- Exportacion DXF ASCII R12 en milimetros con capa `CUT`.
- Modo terrario con ventilacion e inserto.

## Uso

Instala dependencias:

```bash
npm install
```

Ejecuta el servidor local:

```bash
npm run dev
```

Compila para produccion:

```bash
npm run build
```

Ejecuta pruebas:

```bash
npm test
```
